# 다고침집수리 홈페이지 — 블로그로 만드는 여러 페이지 사이트

네이버 블로그 글을 읽어 홈페이지 페이지를 자동으로 만드는 작업 폴더입니다.
레퍼런스: https://luckyrepair.co.kr (블로그 기록을 분야·지역별로 나눠 보여주는 구조)

운영 주소: https://koniture-g-south.co.kr

## 폴더 구성

| 폴더 / 파일 | 역할 | 직접 고치나 |
|---|---|---|
| `data/content.json` | **편집 데이터** — 업체 정보, 분야 8개 설명, 글마다 지역·분야·제목·요약 | ✅ 여기만 고치면 됨 |
| `data/posts.json` | 블로그에서 가져온 원문 (자동 생성) | ❌ |
| `data/img/` | 블로그 사진 원본 (자동 생성) | ❌ |
| `data/banners.json` | 여러 글에 반복된 홍보 카드 목록 — 홈페이지에서 제외 (자동 생성) | ❌ |
| `static/` | 디자인(css), 동작(js), 파비콘, 네이버 인증 파일, .htaccess | 디자인 바꿀 때만 |
| `scripts/` | 제작 스크립트 | ❌ |
| `dist/` | **완성본 — 이 폴더 안의 내용 전체를 서버에 올림** | ❌ (매번 새로 만들어짐) |

## 다시 만드는 순서 (새 블로그 글이 쌓였을 때)

```
python scripts/scrape.py hjadg5582      # 1. 블로그 최근 50개 글과 사진 가져오기
python scripts/find_banners.py          # 2. 반복 홍보 카드 찾기
python scripts/build.py                 # 3. dist/ 에 홈페이지 만들기
python scripts/check_links.py           # 4. 깨진 링크 검사 (0개여야 함)
```

새 글이 생기면 1번 후 `data/content.json` 의 `posts` 에 그 글을 추가해야 합니다
(지역·분야·새 제목·요약). Claude에게 "새 블로그 글 반영해줘"라고 하면 됩니다.

사진을 눈으로 검수하려면 `python scripts/contact_sheet.py` → `data/sheets/` 에 모음 이미지가 생깁니다.

## 페이지 구성 (총 83개)

| 주소 | 내용 | 개수 |
|---|---|---|
| `/` | 메인 — 증상별 안내, 분야 8개, 기록 숫자, 최근 사례, 지역 | 1 |
| `/service/<분야>/` | 분야 설명, 실제 고객 문의, 사진, 사례, 자주 묻는 질문 | 8 |
| `/portfolio/` , `/portfolio/<글번호>/` | 사례 전체 목록 + 사례 1건씩 | 51 |
| `/area/` , `/area/<지역>/` | 지역 목록 + 지역별 기록 (사례 2건 이상 지역만) | 10 |
| `/area/<지역>/<분야>/` | 지역+분야 (사례 2건 이상 조합만) | 12 |
| `/contact/` | 상담 안내 | 1 |

지역·지역+분야 페이지는 **사례가 2건 이상일 때만** 만듭니다. 사례 1건짜리 지역 페이지를
수십 개 찍어내면 구글이 스팸(도어웨이 페이지)으로 볼 수 있기 때문입니다.
기준은 `scripts/build.py` 의 `MIN_PAGE = 2`.

## 블로그 원문을 그대로 쓰지 않는 이유

같은 글이 블로그와 홈페이지에 둘 다 있으면 네이버가 한쪽만 보여줄 수 있습니다.
그래서 사례 페이지는 **새로 쓴 요약 + 현장 사진 + 블로그 원문 링크**로 구성합니다.
블로그에 있는 고객님 말씀(따옴표 문장)과 작업 인원·시간은 그대로 인용합니다.

## 서버에 올리기

FileZilla 왼쪽에서 `dist` 폴더를 열고, **안의 내용 전체**(폴더 포함)를 서버 최상위 폴더로 끌어다 놓습니다.
- 파일 437개, 약 28MB
- `index.html`, `robots.txt`, `sitemap.xml`, `.htaccess` 는 덮어쓰기
- 예전 사진 `1.jpg`~`10.jpg`, `1.png`~`6.png` 는 더 이상 쓰지 않으므로 서버에서 지워도 됨
- 네이버 소유확인 파일(`naverfe2d…html`)은 지우지 말 것

- [ ] 푸터 사업자등록번호 · 대표자명 (레퍼런스는 표시함)
